# fahrul4215 golang boilerplate

## Installation

### libraries

```bash
go get github.com/joho/godotenv #env config
go get golang.org/x/crypto/bcrypt #hash password
go get github.com/golang-jwt/jwt/v4 #JWT
go get github.com/gin-gonic/gin #HTTP framework
go get gorm.io/gorm #ORM
go get gorm.io/driver/mysql #mysql driver
go get github.com/go-playground/validator/v10 #Data validation
go get github.com/boombuler/barcode #Generate Barcode
```

## Usage

```bash
make build-run
```
